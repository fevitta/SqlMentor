Implementar 11 tasks abertas do `tasks_mariadb.md` (T3, T5, T8, T9, T11-T17) que corrigem labels Oracle-centric em reports MariaDB, bugs no parser/collector, e adicionam funcionalidades como `inspect <digest>`.

- **T17**: `optimizer_switch` default alterado de `""` para `None` — elimina warning espurio em 100% dos reports
- **T5**: Early return em `_compress_plan` para MariaDB — regras R1-R8 (pipe-format Oracle) nao se aplicam a planos JSON
- **T12**: Lookup case-insensitive no `index_table_map` da View Expansion — resolve mismatch MariaDB lowercase vs Oracle uppercase
- **T13**: Labels CLI de resumo: "ANALYZE FORMAT=JSON" e "Runtime Stats" para MariaDB

- **T16**: `_format_table_stats` (Pages vs Blocks, sem Sample Size/Parallel Degree) e `_format_indexes` (sem BLevel/Clustering Factor) para MariaDB
- **T9**: Parser filtra literais com espaco e nomes vazios em WHERE columns
- **T8**: `UNKNOWN` sql_type agora coleta plano estimado mesmo sem `--execute`
- **T15**: `last_analyze_stats()` filtra ANALYZE wrapper para obter digest correto da query original
- **T11**: Inspect MariaDB com `sql_text_original`, `setup_consumers`, diagnostico no doctor, fallback CLI/MCP
- **T3**: Verificado resolvido por T2 + T12

## Decisoes tomadas

- **T5**: Em vez de portar regras R1-R8 para JSON, optou-se por early return apos R5 thresholds — MariaDB JSON e estruturalmente diferente do pipe-format Oracle, regras de colapso nao fazem sentido
- **T15**: `last_analyze_stats()` filtra por `SQL_TEXT NOT LIKE 'ANALYZE%%'` em vez de usar OFFSET — mais robusto contra variacao no numero de queries internas
- **T11**: Fallback em cadeia: `sql_text_original` (history_long) → `sql_text_by_id` (DIGEST_TEXT) → diagnostico de consumers
- **T8**: Removida exigencia de `execute=True` para UNKNOWN — o banco aceita o SQL mesmo quando sqlglot nao parseia
